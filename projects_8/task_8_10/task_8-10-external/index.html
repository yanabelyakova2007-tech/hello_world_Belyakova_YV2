Добро пожаловать на главную страницу!

Это первая страница моего сайта. Стили подключены через внешний CSS-файл styles.css. Обратите внимание, что обе страницы (index.html и about.html) выглядят одинаково, потому что используют один и тот же CSS.

Внешние таблицы стилей — это стандарт индустрии. Они позволяют менять дизайн всего сайта, отредактировав всего один файл. Представьте, что у вас сайт из 100 страниц — без external CSS пришлось бы править каждую страницу!

Преимущества external CSS:

  • ✅ Разделение структуры и оформления — HTML отвечает за содержание, CSS — за внешний вид
  • ✅ Переиспользование — один файл на весь сайт
  • ✅ Кэширование — браузер загружает CSS один раз
  • ✅ Удобство поддержки — все стили в одном месте
