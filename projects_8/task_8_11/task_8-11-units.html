📏 Эксперимент: единицы измерения в CSS

Попробуйте изменить размер окна браузера и поменять font-size в html (в коде: html { font-size: 20px; }). Наблюдайте, как ведут себя блоки.

Блоки внутри контейнера (ширина контейнера = 100% от body)

📐 .size-px — width: 200px (фиксированная, не меняется)
📏 .size-em — width: 15em (зависит от font-size текущего элемента)
📐 .size-rem — width: 12rem (зависит от font-size html)
📊 .size-percent — width: 50% (от ширины родителя .container)
🖥️ .size-vw — width: 30vw (от ширины окна браузера)

📖 Что вы должны заметить:

  • px (пиксели) — блок НЕ меняет размер при изменении окна
  • em — зависит от font-size текущего элемента (по умолчанию наследуется от родителя)
  • rem — зависит от font-size корневого элемента html
  • % (проценты) — зависит от ширины РОДИТЕЛЯ (.container)
  • vw (viewport width) — зависит от ширины ОКНА БРАУЗЕРА

🔬 Попробуйте сами:

  1. Измените html { font-size: 20px; } на 16px — блоки с rem изменят размер
  2. Уменьшите окно браузера — блоки с % и vw изменят размер
  3. Блок с px останется неизменным в любом случае
