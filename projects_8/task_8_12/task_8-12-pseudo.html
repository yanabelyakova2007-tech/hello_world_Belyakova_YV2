🎯 Задание 3: Псевдоклассы и селекторы

📝 Список дел (псевдоклассы :first-child, :last-child, :nth-child(3n))

  1. 🔹 Первый пункт — будет синим (:first-child)
  2. 🔸 Второй пункт — обычный
  3. 🟢 Третий пункт — каждый третий получает зелёную полосу (:nth-child(3n))
  4. 🔹 Четвёртый пункт — обычный
  5. 🔸 Пятый пункт — обычный
  6. 🟢 Шестой пункт — каждый третий получает зелёную полосу
  7. 🔹 Седьмой пункт — обычный
  8. 🔴 Восьмой пункт — последний будет красным (:last-child)

📌 Обратите внимание: у всех пунктов, кроме первого, есть верхняя граница (стиль li:not(:first-child)).

🔗 Примеры ссылок (:hover, :active, селектор по атрибуту)

  • 📄 Внутренняя ссылка (about.html) — не меняет цвет при наведении
  • 🌐 Внешняя ссылка (https://stepik.org) — при наведении станет красной
  • 📑 Ссылка на PDF-файл — красная с розовым фоном (селектор a[href$=".pdf"])

📌 Наведите мышь на любую ссылку — цвет изменится (:hover). Кликните — сработает :active.

📝 Форма обратной связи (:focus, :required)

📌 Поле E-mail — обязательное (required): красная полоска слева. При клике на поле — зелёная подсветка (:focus).

✅ Использованы псевдоклассы: :first-child, :last-child, :nth-child(even), :nth-child(3n), :not(), :hover, :active, :focus, :required, :valid, :invalid

✅ Использованы селекторы по атрибуту: [href$=".pdf"], [href^="https"]

✅ Использованы псевдоэлементы: ::after, ::placeholder, ::selection
